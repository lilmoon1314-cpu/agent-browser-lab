# Agent Browser Lab

> 一个系统性评测 **Browser Use Agent 能力边界**的开源实验项目：探针任务矩阵 + 结构化评分框架 + 真实实验记录。

## 这是什么

AI 操控浏览器替人干活（Browser Use）是当前 Agent 领域最热的方向之一，但各家宣传只剩一个"成功率"数字，回答不了三个真问题：

1. Agent 在**真实网站**上到底能稳定完成什么？
2. 失败发生在哪个环节——是点错了（grounding）、理解错了（规划），还是中途放弃了？
3. 这些失败模式指向哪些**高价值的产品机会**？

本项目用一套可复用的实测框架回答上面的问题：**12 个探针任务 × 统一评分卡 × 失败归因五分类**，所有任务在真实中文网站上执行，全程只读、安全合规。

## 当前状态

## 核心设计一览

- **任务矩阵**：难度（L1 单页查找 / L2 多步交互 / L3 跨站聚合与异常）× 能力类型（信息查找、表单交互、提取总结、歧义识别）
- **评分卡**：结果（成功/部分/失败）+ 过程指标（步数/耗时/异常次数）+ **失败归因五分类**（规划错误 / grounding 错误 / 信息提取错误 / 异常处理失败 / 提前放弃）
- **安全约束**：全部任务只读——不登录、不下单、不支付、不发布内容

## Roadmap

见 [ROADMAP.md](ROADMAP.md)：横测报告 → 自动化 Benchmark（带 checker 与排行榜）→ 基于评测发现的效率 Agent 原型。
