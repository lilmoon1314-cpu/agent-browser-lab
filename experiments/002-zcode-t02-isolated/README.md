# Experiment 002 — T02 B站 UP 主最新视频查询（v0.2 角色分离协议）

> 本实验是方法论修订至 v0.2 后的首个有效实验：设计者、被测执行者、评分者三方上下文隔离。
> 被取代实验：[001](../001-zcode-t02/README.md)（三角色未分离，因污染降级为 harness 冒烟测试）。

## 协议执行情况

| 角色 | 承担者 | 上下文内容 |
|------|--------|-----------|
| 设计者 | 主会话 | 知道一切（任务、方法论、评分标准） |
| 被测执行者 | 独立子智能体（每轮全新干净上下文） | **仅**：任务指令原文 + 动作集 + 页面观察文件 + 机械执行日志 |
| 评分者 | 独立子智能体（全新干净上下文） | **仅**：任务原文 + 完成定义 + 归因代码定义 + 执行轨迹 + 最终答案 |
| harness 操作员 | 主会话 | 机械执行动作、原样记录观察，不注入任何提示 |

执行者提示词中不含：评分标准、失败分类、任务背景、任何关于"如何绕过障碍"的信息。

## 结果

- 执行者最终答案：《比电影更夸张？专业保镖到底在做什么？》，发布于 2026-09-22 17:00:00
- 评分员独立判定：**成功**（confidence: high；评分员自行用视频列表排序做了交叉核对——次条为 9月16日，确认第一条为最新）

## 执行轨迹摘要（4 轮决策 / 3 次浏览器动作 / 1 次卡点 + 1 次自主恢复）

| 轮 | 执行者决策 | harness 执行结果 |
|----|-----------|------------------|
| 1 | `goto space.bilibili.com/946974/video` | 成功。**执行者凭模型先验知识直达 UP 主空间视频页，完全跳过搜索** |
| 2 | `click_text "比电影更夸张？专业保镖到底在做什么？"` | **失败：目标元素被导航 tab 遮挡**（click actionability 超时，原错误已记录） |
| 3 | `goto bilibili.com/video/BV1J7hE6aEDQ/`（URL 从页面快照中的链接构造） | 成功。**自主换策略：放弃点击路径，改为直达 URL** |
| 4 | `final_answer` | 任务终止 |

## 归因规则的本次应用

- 点击被遮挡：计入 `anomalies` + 自主恢复（`self_recovery: true`），**不计入失败归因**——因为最终结果达标。失败归因（F1–F5）只在最终未达标时使用。
- 若未来模型在同卡点后无法恢复，则该任务进入"异常恢复"失败归因类（F4），并成为新 benchmark 任务的候选。

## 与 experiment-001 对比，以及为什么两者不能直接比

| | 001（污染，已降级） | 002（v0.2 有效） |
|---|---|---|
| 路径 | 搜索 → 建议面板 → 空间页 | 先验知识直达空间页 |
| 卡点 | Enter 失效、建议面板、新标签页 | 点击被导航遮挡 |
| 动作数 | 7 步 | 3 次浏览器动作 / 4 轮决策 |

两条路径、两类卡点完全不同 → **单次执行不构成能力结论**。同一任务需要 ≥3 次重复、探针矩阵需要多任务分布统计——这正是下一步必须自动化 harness 的理由。

## 已知残余局限（诚实声明）

1. **操作员效应**：动作由主会话（设计者所在上下文）机械执行。动作映射规则固定（文本精确匹配优先 → 子串匹配、多处匹配取 DOM 顺序第一个、失败原样回报原文），但理论上无法完全排除操作员层干扰。彻底消除 = 自动化 harness（ROADMAP Sprint 2）。
2. **先验知识优势**：执行者具备模型级先验知识（知道 UP 主空间 ID、B站 URL 规则），与真实用户场景一致，但意味着该任务对"见多识广"的模型偏简单 → 任务设计需考虑先验知识可绕过的任务比例。
3. **单样本**。
