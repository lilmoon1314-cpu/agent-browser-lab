# 探针任务定义（12 个）

> 全局约束：所有任务**只读不写**——不登录（T12 除外且必须用专用小号）、不下单、不支付、不发布内容。单任务执行限时 15 分钟，超时记为"部分完成"。遇到验证码/风控：截图留证，记为一次异常，尝试 1 次后跳过记 F4。

## L1 单页查找

### T01 豆瓣图书信息
- **指令**：在豆瓣找到《置身事内》（兰小欢）的页面，报出它的评分和评价人数。
- **完成定义**：评分误差 ≤0.1，评价人数误差 ≤10%。

### T02 B站 UP 主最新视频
- **指令**：找到 UP 主「影视飓风」最新一期视频，报出标题和发布时间。
- **完成定义**：标题完全一致，发布时间误差 ≤1 天。

### T03 GitHub 仓库信息
- **指令**：查 browser-use/browser-use 仓库的 star 数和最新 release 版本号。
- **完成定义**：star 数误差 ≤2%，版本号完全一致。

## L2 多步交互

### T04 12306 车票查询
- **指令**：查询 2026-10-01 北京→上海的高铁班次，报出最便宜的二等座价格和对应车次。**只查不买。**
- **完成定义**：价格、车次与人工核对一致。
- **备注**：12306 可能有验证码/风控，遇到则按全局约束处理，异常本身就是有价值的观察数据。

### T05 地图路线对比
- **指令**：在高德地图查「北京站 → 首都国际机场」，分别报出驾车和公共交通的预计耗时。
- **完成定义**：两个耗时均报出，误差 ≤15 分钟。

### T06 电商搜索与排序
- **指令**：在京东搜索「机械键盘」，按价格从低到高排序，记录前 3 名商品的名称和价格。**不购买。**
- **完成定义**：3 个商品名+价格与人工核对一致。

### T07 知乎要点总结
- **指令**：在知乎搜索「成年人 ADHD 自我管理」，找到赞数最高的回答，总结 3 个核心要点。
- **完成定义**：目标为当前最高赞回答（允许并列），要点忠实于原文。

### T08 信息聚合与判断
- **指令**：查询北京明天的天气，给出「是否适合户外跑步」的结论和理由。
- **完成定义**：天气数据准确，结论与数据逻辑自洽。

## L3 跨站聚合与异常

### T09 跨站比价
- **指令**：分别在京东和淘宝查 AirPods Pro 2 的价格，输出一张 markdown 对比表（平台/价格/链接）。
- **完成定义**：两个平台价格均正确，表格格式完整。

### T10 跨站信息汇总
- **指令**：汇总电影《哪吒之魔童闹海》的豆瓣评分和猫眼累计票房，输出表格。
- **完成定义**：数值误差 ≤2%，格式完整。

### T11 歧义识别
- **指令**：「查一下李健的年龄。」（存在歌手李健等多个同名人物）
- **完成定义**：Agent 主动澄清问的是哪位，或明确列出多个同名人物分别作答。直接默认其中一人且不提示歧义 = 不通过（归因 F1）。
- **考察点**：指令模糊时的澄清行为——这是真实用户指令的常态。

### T12 登录态只读任务（可选）
- **指令**：登录专用测试 GitHub 小号，查看自己的 star 列表并报出 star 了几个仓库。
- **完成定义**：数量正确。
- **⚠️ 安全约束**：必须使用专用测试账号，禁止使用任何主账号/真实账号。
